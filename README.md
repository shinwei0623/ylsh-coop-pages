# 宜中數位合作社公開入口

這是 GitHub Pages 的公開靜態前端，不是原 GAS 管理系統的完整搬移。

目前提供公開介紹與校內服務入口。登入、訂單、申請、審核、成果及私人照片仍由原 GAS 網站處理。未匯出任何校內限定資料。

編輯 main 分支後，GitHub Pages 由 main 根目錄發布。完整後端程式位於私有 `shinwei0623/ylsh-coop-campushub`。不得在此庫放入學生資料、私人照片、OAuth token 或校內工作表匯出。

要讓合作教育成果直接在公開 Pages 展示，還需另行設計並驗證「對外公開授權」及安全發布資料流，不能沿用既有校內核准就擴大公開。
